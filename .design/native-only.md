# 定制 TS7 原生工具链收敛

2026-10-06，用户明确撤销双工具链方向：删除 Vue、React、Svelte 适配及宿主演示、测试和传统编译器，只维护项目定制 TS7-Go。此前 TS6 分工和 core 双产物研究不再作为实施目标。

## 实施范围

- 删除四个包：compiler、vue、react、svelte，以及 apps/hosts、宿主专属测试与验证脚本、Babel 工具和配置。
- 将独立框架语义测试迁到 native，直接调用真实原生接口；保留状态、组件、JSX、绑定、诊断、映射、SSR、开发更新和独立包消费覆盖。
- Vite 与主示例固定原生服务，移除后端选择及回退。工作区构建、检查、声明和 CLI 使用同一固定的定制 SDK。
- 发布与 CI 只维护 core、use、ssr、vite、native 及六个平台包。新候选使用 RC4，不覆盖 RC3 的固定提交与产物。
- core 保留一份源码与一套产物。页面入口仍是框架本身的能力，不随外部宿主删除。
- 删除失效的 TS6 双线路实验、宿主研究和使用说明；保留仍有参考意义的框架历史记录并标明状态。更新现行安装、开发、包结构与支持说明。

## 验收

本地执行定制 SDK 构建/检查、Node 语义测试、开发态验证、Chromium 主示例及工作区外包消费。CI 保留六种实际架构及完整三浏览器矩阵，去掉重复后端和宿主任务。生产浏览器依赖图不得包含编译器、TypeScript、Babel 或外部宿主框架。

Prettier/Oxc 与 Oxlint 暂作为独立工程工具保留；删除 Svelte 格式插件。未使用的 coverage 插件因间接引入 Babel 也已移除，测试用例保留。关闭 peer 自动安装，显式声明根 Vite 依赖，防止已删除工具通过可选 peer 回流；锁文件的实际包清单不再含 Babel、Vue、React、Svelte 或 coverage 插件。这些保留工具没有共享定制 TS-Go 的 AST，不将清理依赖等同于跨工具共享已完成。

后续工具接入的源码核对、只读实验与优先级见 [定制 TS7 工具共享研究](native-tooling.md)。

## 本地验证结果

- 定制 SDK 的全仓构建、类型和框架诊断、生成数据及 lint 通过。
- 原生编译与运行时 Node 用例共 322 项；两个类型负例分别在类型声明层和真实原生诊断用例中验证，未允许 `@ts-expect-error` 绕过框架约束。
- Chromium 主示例 112 项通过，宿主专属浏览器用例已移除。
- 开发态状态保留、重置、错误恢复、资源清理和 SSR 更新通过。
- 十一包工作区外安装、组件库声明、CSR/SSR、绑定、路由和卸载通过。
- LSP 错误修复、补全、14 个绑定导航位置、重命名、依赖更新与隔离通过。
- 原生基准命令完成一轮功能校验，临时报告已删除；该轮与其他验证并行，不作为新的性能排名。

完整三浏览器和六平台矩阵由本次提交的 CI 执行，未完成的远端检查不记为已通过。RC4 尚未发布；旧 RC3 发布任务在 GitHub Release 创建阶段返回 403，当前不继续发布已撤销的旧清单。
