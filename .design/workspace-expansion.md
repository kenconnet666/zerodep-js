# SSR 与示例工作区扩展

日期：2026-10-01。

本阶段建立 SSR/CSR 工程入口、整理工作区、补充生产化路线，并创建 GitHub 仓库交付。核心响应式、JSX 编译、组件运行时和通用 hydration 继续先讨论后实现。

## 目录与职责

- `packages/core`：未来框架核心，继续保持空入口。
- `packages/ssr`：先实现文档模板组合和 SSR/CSR 模式分发；未来接入真正的组件服务端渲染器。
- `apps/example`：由原 playground 整理而来，依赖工作区构建产物，提供客户端和服务端入口、开发服务器、生产服务器及模式切换。
- `docs/production-plan.md`：记录生产化阶段、验收要求、API 形态与待确认决策。

## 本轮验证边界

- SSR 响应必须在 JavaScript 执行前包含页面内容。
- CSR 响应保留空应用容器，由浏览器入口创建页面。
- 通过 query 或启动参数切换模式，两个模式均可运行工程探针交互。
- 当前页面使用原生 DOM 工程探针；不得把它说成已经实现了框架响应式或通用 hydration。
- 生产服务器仅从构建产物加载 SSR 入口；开发服务器使用 Vite middleware 与 SSR 模块加载。
