# CSS 包归属

仅维护 zerodep-js 本仓库：css 提供作者/主题机制/宿主，compiler 提供框架转换，core 提供 DOM/SSR 通用消费协议，ui 提供具体主题和组件。相邻 CSS 仓库不继续开发；没有 Vue/Svelte adapter 或扩展注册体系。

2026-10-11 新作者契约、bx、主题变量和阶段验收统一见 [CSS 重构计划](../docs/css-redesign-plan.md)。当前公开使用说明见 [CSS](../docs/css.md)，包入口见 [包边界](../docs/packages.md)。旧集成步骤、字符串作者和全面隐式转换已被新计划取代；历史内容由 Git 保留。
