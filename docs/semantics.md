# 执行中的语义契约

2026-10-01：用户授权目标模式，要求完整生产可用、适当取舍、人工可维护，并允许有依据地调整实现与测试。本文记录执行选定的契约；调整时记录原因与迁移影响，不把旧候选文档当成永远不变的限制。

## 状态与计算

- `_state` 显式声明变量式状态，普通读写由编译器转换；普通变量、函数传参、对象字面量和 return 保持取值语义。
- 普通对象/数组按属性跟踪；不代理类、DOM、Date、Map/Set。原始对象不隐式深拷贝，经原始别名绕过代理的操作不承诺通知。
- 字段依赖缓存不永久保留已结束的临时查询；实际观察者和冷派生仍持有需要的依赖。卸载同步解除订阅，缓存的物理回收遵循 JavaScript GC，不改变后续读取和更新语义。
- `_state.raw` 是显式浅状态入口，只跟踪整体替换。它不要求使用 `.value`。
- `_derived` 与 `_derived.by` 为纯计算，按需执行、动态跟踪同步读取；禁止计算期间写状态或建立副作用。
- 相等性基线为 `Object.is`。派生失效不等于值已变化，结果相等时跳过下游 effect。
- 写入立即可读，派生立即读取也必须一致。中间连续写入允许合并 DOM 和 effect 更新。
- `_untrack` 仅取消读取的依赖登记，不豁免纯派生的写入限制。

## 生命周期与调度

- 组件初始化语句执行一次；返回表达式和 JSX 动态区域跟踪后续更新。直接返回条件、逻辑表达式、数组或响应式值都可更新；语句级 if / 提前返回的路径选择仍是初始化逻辑。
- 条件选择结果不变时保留分支实例，避免父级对象刷新但条件仍为 true 时重建子组件。普通局部变量与辅助函数传参仍保留取值语义。
- `_effect` 必须属于组件、分支、列表行或显式 `_createRoot`。禁止无作用域创建不可回收的订阅。
- effect 首次和后续执行在微任务批次内，DOM 更新先于用户 effect；同步创建/更新过程中不运行半初始化的用户副作用。
- `prop:*` 绑定在完整 DOM 更新后、用户 effect 前提交；卸载撤销尚未执行的任务，解除绑定恢复接管时初值。它不在 SSR 执行。
- 渲染队列按作用域深度先父后子，同深度保持入队顺序；父分支失效时先销毁子绑定，不能因依赖重新订阅改变安全更新顺序。
- 重跑先销毁上一轮的子作用域，再按注册的逆序执行清理；卸载同样清理，重复 dispose 无副作用。
- `_onCleanup` 归属当前作用域；effect 返回的函数属于该轮清理。清理不收集依赖。
- `_batch` 合并通知；`_flushSync` 用于需要立即观察 DOM 的明确边界，禁止在计算或正在执行的 effect 中重入刷新；`_tick` 等待本轮刷新。
- 不跨 await 隐式保留跟踪或作用域。异步请求由取消、清理与过期结果判定负责。
- 一处异常不阻止其他独立作用域清理或独立任务更新；错误继续传播，不能吞掉。后续错误边界沿组件所有权实现。

## 组件与 props

- `_component` 为显式组件边界，保留原函数泛型签名；普通函数仍按普通函数调用。
- 顶层参数解构、别名、默认值与 rest 是正式支持目标。复杂嵌套解构先提供明确诊断和 `props.user.name` 等替代写法，不静默失去响应性。
- 输入绑定只读；深层对象不递归冻结。业务写入优先通过回调交回拥有者。
- 默认值仅在输入为 undefined 时使用。每个实例独立缓存，无依赖默认值稳定，有依赖 fallback 按依赖更新；显式值暂时覆盖 fallback。
- 默认表达式引用前面参数时读取其当前值，不放宽前向引用规则。默认值是纯计算，不能放订阅或发请求。
- `_state(initial)` 只取创建时初值，后续 prop 变化不重置状态；回调 prop 在事件发生时读取最新函数。
- rest 是排除已解构键的实时视图，支持新增、删除、覆盖次序；不是初始化时复制的普通对象。
- TS 原生检查与框架诊断共同构成语义门槛。跨回调沿用实时绑定的外层收窄不受支持，需在本次调用重新读取判空或显式保存快照；无法可靠转换的形式应报错。
- 初始化 if 的收窄也不能直接延续到持续求值的 JSX；将条件放进返回表达式或 JSX 动态内容，或者显式捕获普通快照。检查覆盖范围、错误码和安全写法见 [开发指南](development.md)。

## 已落地的变量编译边界

- 支持命名导入、导入别名和静态命名空间成员，支持 let/const 初始化、普通赋值、复合/逻辑赋值、自增自减、BigInt、闭包与对象简写。只读派生和 const 绑定不可重新赋值。
- 宏只能直接初始化单个命名变量，不能作为普通值转交；复杂解构写入、循环赋值目标和直接 eval 给出明确诊断，保留逐项赋值的自然写法。
- 暂不直接导出响应式绑定，跨模块通过普通函数、getter 和操作方法暴露；普通返回值仍是当时的值，不通过隐式活引用改变 JavaScript 含义。
- 未接入编译器时宏立即报错。`zerodep-js/internal` 是编译输出协议，不是第二套用户 signal API；编译结果及 SSR 在初始化时检查协议，版本不匹配报告 ZJ_RUNTIME_ABI。

## 内容、列表与根入口

- JSX 使用框架自己的元素、事件和 children 类型；原生事件不包装成 React 事件。
- JSX 值是可重复插入的渲染描述；每个插入点创建独立 DOM 与作用域，不把已存在节点从别处搬走。普通 children 可转发；参数化内容使用显式调用的 render 函数，不自动执行任意函数值。
- 同一 JSX 位置的组件/动态标签保持实例，标签或 key 变化才重建。key 只接受字符串、数字、symbol，不传入组件 props，也不写入 DOM；业务标识使用 id 等普通字段。
- 原生事件保持浏览器派发与 currentTarget；ref 用于取得元素或返回清理函数，需要已连接 DOM 的测量放在 effect 中。style 字符串/对象和 CSS 变量受支持，长度单位由调用方显式提供。
- style 共用声明序列化，客户端在模型文本变化时整体替换；对象值须是完整单声明值，完整字符串按浏览器声明列表解释。CSS 类型取自 csstype 生成数据，词法边界用 CSS Tools tokenizer，不维护另一套 CSS 文法。
- HTML、SVG 和 MathML 的属性序列化及命名空间使用共同规则；属性别名先合并最终值再更新 DOM。`prop:*` 用于客户端成员，`on:*` / `oncapture:*` 用于精确事件名；完整约定及原生类型审计见 [原生元素](native-elements.md)。
- value/checked 与 defaultValue/defaultChecked 分别表示受控值和首次默认状态；同值归一化也校准 DOM，组合输入期间延后 value 回写。文本 onInput 即时同步，只有原生 onChange 时允许编辑到提交。
- 表单 reset 默认动作后，受控字段重新服从模型，非受控字段回到首次默认值；取消 reset 不强制重置。select 随结构及选项变化重新匹配模型，文件输入只允许空 value 用于清空。
- `For` 使用稳定 key；内联回调的 row/index 是编译器识别的实时绑定。同 key 替换数据读取新对象、保留行实例；删除销毁，重复 key 报错。
- For 接受数组、null 或 undefined；缺失数组视为空，fallback 随空态创建与销毁。使用命名导入（可重命名）或静态命名空间标签，以及内联同步 row/index 回调；写入参数或用外部回调代替会报错，普通辅助回调仍按 JavaScript 传值。
- context 用 _createContext / _provideContext / _useContext 表达，值按最近作用域继承，内层可覆盖；同一作用域只提供一次。变化值使用状态对象或 getter，普通数值保持取值语义。
- ErrorBoundary 捕获子树的初始化、渲染与排队 effect 错误。fallback 接收错误与 reset，reset 重建子树；fallback 自身失败交给外层。原生事件和自行启动的异步任务仍由调用方处理错误。
- 普通 map 保持普通计算，不默认为有身份保留的列表机制。
- `_mount(App, { target, props })`、`_hydrate(App, { target, props })` 返回 disposer；SSR 从同步 `renderToString(App, { props })` 建立正确基线。
- 完整生产目标包括受控表单、IME/选区、错误恢复、context、ref、属性转发、声明消费、HMR、SSR/hydration 与安全边界；不以只支持计数器代替完成。
- SSR/CSR 由应用入口选择，切换模式允许重新导航；不承诺把已挂载实例无刷新迁移到服务端。
- SSR 每请求独立 scope，用户 effect 不在服务端执行；不自动序列化全部 props，客户端初始数据需要明确的传输边界。
- hydrate 先验证已有结构，再激活绑定、事件与 ref；正常接管复用节点。默认 mismatch=throw，验证失败保留 HTML；可显式选择 replace 并通过 onMismatch 记录诊断。
- noscript 子树作为服务端备用内容序列化，客户端不初始化其中的组件或建立子树绑定；接管保留其原始内容。其他交互结构仍使用严格匹配规则。
- 原始文本元素在 CSR/SSR 共用文本与结束边界校验，script 禁止会破坏 HTML 解析的双重转义；JSON 使用 serializeData。标签名称统一 HTML/SVG 规范，plaintext 与不能往返的元素名明确报错，不将无效解析结果交给 hydration 掩盖。
- SSR 错误边界只在协议中标记降级，不自动传输异常；客户端对该区域局部重试。受控输入已有编辑时尽量保留并交给已安装的原生回调，完整输入边界继续专项验证。

## 交付与合理取舍

目标是有清楚支持范围的完整生产框架，而不是对所有可能特性的承诺。用户已批准的路由与存储从 RC3 起通过独立 zerodep-use 的 router/storage 子入口提供，并以同版本 peer 共享 core。快照、通用生命周期与页面入口留在 core；全栈数据层、RSC、流式 SSR、动画与 UI 组件库不自动进入核心职责。真实使用证明缺失能力影响生产时，应调整计划并补齐。

以小而清晰的职责为准，允许引入能够改善正确性、完整性或维护成本的依赖，不机械追求零依赖。包大小和运行速度没有硬性指标，仍记录基线并检查影响实际使用的退化。命名、目录、私有 helper 可以随真实职责重整；不为兼容尚未发布的实验内部接口保留重复抽象。

应用、SSR 与预编译组件库通过 peer dependency 共享 core；框架包使用统一发布版本。ESM、类型声明、源码映射和公开类型出口通过工作区外的 tgz 安装验证，具体门槛见 [包产物与独立消费](packages.md)。

开发更新以正确卸载和重新挂载为基线，局部状态重置；不将自动状态迁移列为生产必需条件。TS7、独立框架检查、Vite 和项目 MCP 诊断桥共同提供开发反馈，标准编辑器不会自动加载 MCP 扩展。

实施中的状态与证据记录在 [执行记录](execution.md)。本地运行相关验证，完整矩阵交给 CI；下次推送前读取上一轮结果，不把 pending 当作通过。Git 提交、重要注释和维护记录使用中文。
