## 已补齐的发布缺口

RC2 实际发布中，npm 已接受上传，但版本与标签延迟可见。旧工具把即时查不到元数据当作失败，再运行可能重复上传。维护修正包括：

- 请求前落盘 attemptedAt，成功回执后记录 acceptedAt；保存使用完整临时文件替换。
- 受理后只核对，版本可见与 next 就绪分开处理；独立查询 dist-tags，避免旧包元数据的缓存影响判断。
- 响应丢失时保留 unknown 状态，不能自动重新发送。完整性冲突直接拒绝。
- 单包等待公开不阻挡后续包；非 ready 退出码为 2，不能误进入验收。
- 四项针对性测试覆盖延迟公开/标签恢复、丢失回执后的重启、记录失败/内容冲突和部分发布；另保留原来的真实临时 Git/打包集成测试。

RC2 恢复使用最初固定的 tgz，未重新打包或覆盖版本。最终注册表验收完成时间为 `2026-10-02T02:15:53.458Z`。恢复用的临时脚本在永久维护工具验证后删除，原始 tgz、release.json 和发布说明保留。

# RC3 编写体验阶段复核（2026-10-06）

在此前 RC2 审查之外，新增 bind、_history、_lazy 和开发检查/HMR 已按明确范围实现，并同步示例、类型、文档与实际消费验证。独立消费涵盖输入写回、历史恢复、按需预编译组件；开发验证涵盖状态迁移/重置、异常恢复、旧资源释放、混合导出、转发入口及开发 SSR 接管。生产构建没有自动注入开发协议。

合理取舍已经写明：历史按显式 commit 记录操作；_lazy 采用同步 SSR 占位；HMR 迁移组件直接声明的本地数据，不承诺整个组件树、外部对象身份和 DOM/焦点保留；检查面板是有界的开发辅助，不伪装成完整 Vue Devtools。_watch、异步/浏览器工具、Map/Set 原地响应式、Portal 等继续处于讨论范围。

本阶段检查不涵盖另一个工作正在处理的 TS7.1 原生补全回归，不覆盖其 LSP、依赖与示例调整。此前版本的语言服务验收不替代当前新版的结果。RC3 的最终完整 CI、干净源码和发布门槛仍须独立确认，尚未发布 npm。
