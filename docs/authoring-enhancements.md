## 使用边界与阶段

1. **输入绑定**：原生 input/textarea/select 的可写绑定复用已有受控输入、IME、reset 和 hydration 机制。文本绑定返回字符串，数字使用显式 valueAsNumber，空数字为 undefined；checked 返回布尔值。组件绑定依据属性和 onXChange 回调配对，父级仍拥有数据。拒绝不可赋值表达式、只读输入和冲突的属性声明。
2. **快照历史**：在 zerodep-use/history 提供 _history，接受与存储相同含义的 read/write。创建时保存基线，commit 记录一次编辑；undo/redo 恢复副本，reset 回到基线，clear 将当前值设为新基线。容量有上限，失败不部分移动历史位置，不代理服务器回滚。
3. **组件按需加载**：_lazy 返回正常的类型化组件，按首次客户端挂载加载代码，支持加载内容、失败恢复和 preload。卸载后忽略迟到结果。SSR 与 hydration 使用相同的初始占位内容，客户端接管后再显示已加载组件；不扩展为流式/异步 SSR。
4. **开发诊断与 HMR**：参考 Vue Devtools 的组件树、状态和时间线职责，给独立框架提供开发态查看入口。运行时采集与界面分离，生产构建不注入开发代码；不为使用 Vue 的调试界面引入 Vue 运行时。HMR 保留可识别、兼容的组件本地数据，布局/类型或导出结构不兼容时明确重置；旧资源必须先后有序清理，不能保留旧 effect/DOM。
