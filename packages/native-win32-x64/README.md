# zerodep-js-native-win32-x64

zerodep-js 原生编译器的 Windows x64 平台包，包含固定 TypeScript 7.1、框架 Go 转换、标准库与构建摘要。由 `zerodep-js-native` 的可选平台依赖选择安装，无需 Go 工具链。

`typescript` 子目录可作为 WebStorm 的 TypeScript 平台 SDK。上游 TypeScript 代码采用 Apache-2.0，见 LICENSE 与 NOTICE.txt；框架修改采用 MIT，见 LICENSE.zerodep。完整使用方式见 [项目仓库](https://github.com/kenconnet666/zerodep-js)。
