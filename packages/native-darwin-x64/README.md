# zerodep-js-native-darwin-x64

zerodep-js 原生 Go 编译器的 darwin-x64 平台包，由对应架构的 GitHub Actions runner 构建、测试并打包。包含固定 TypeScript 7.1、框架转换、标准库与构建摘要。由 `zerodep-js-native` 的可选依赖选择安装，用户无需 Go。

`typescript` 子目录可作为编辑器的 TypeScript 平台 SDK。上游采用 Apache-2.0（LICENSE/NOTICE.txt），框架修改采用 MIT（LICENSE.zerodep）。使用与发布流程见[项目仓库](https://github.com/kenconnet666/zerodep-js)。
